# Screenshot needed — Ziqpu

Drop a PNG in this folder and the build README will pick it up.

**The one shot to get:** the app doing its actual job, mid-task, with real content on screen.
Not a splash screen and not an empty state — a recruiter is deciding in seconds whether this is
a real product, and an empty window reads as a prototype.

Then replace the "Screenshot needed" line in `../README.md` with:

```markdown
![Ziqpu](./screenshots/01-main.png)
```

**Window, not full desktop.** Crop to the app. A pinned browser tab bar or a taskbar makes a
build look like a homework submission rather than a product.
